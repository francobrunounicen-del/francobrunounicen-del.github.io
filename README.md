Descripción del Proyecto
El proyecto consiste en el desarrollo e implementación del maquetado web interactivo de alta fidelidad para la plataforma de videojuegos GameZone Arcade, tomando como base el diseño previo en Figma.

La aplicación fue construida bajo un enfoque Mobile First para la Home y responsivo para el resto del sitio, utilizando únicamente tecnologías web nativas (HTML5, CSS3 y JavaScript Vanilla), sin uso de frameworks de JS (como React, Angular o Vue) ni librerías de CSS (como Bootstrap), garantizando animaciones nativas y optimización de rendimiento.
